How to read this report

Matching uses enclosing class, method name and parameter types. Renamed methods or changed parameter types appear as removed and added. This report is review evidence; it does not establish correctness, effort or misconduct.

Explicit methods and constructors in top-level and member classes are compared. Fields, initializers, local/anonymous-class methods, imports and implicit constructors are outside method comparison. The existing whole-file starter analysis remains separate.
